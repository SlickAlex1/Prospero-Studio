**Prospero Studio** is an independent, unofficial project by [SlickAlex](https://github.com/SlickAlex1),
published for **software preservation, homebrew development, interoperability research and compatibility
testing**.

## What this project is

- A launcher and automation script written from scratch in Python. It prepares folders, runs other
  open-source programs with documented options, and shows their settings in a window.
- Free software under the GNU General Public License v3.0 or later (see [LICENSE](LICENSE)).

## What this project is not, and does not contain

- **No game content.** No games, game files, assets, saves or links to them, and no instructions for
  obtaining them.
- **No Sony software.** No firmware, system software, SDK files, libraries or code from Sony Interactive
  Entertainment.
- **No keys and no decryption.** It contains no encryption keys and cannot decrypt anything. It only works
  on files that are *already decrypted*, and the converters it uses refuse encrypted files.
- **No circumvention of copy protection** or of any other technical protection measure.
- **No bundled third-party code or binaries.** AnyPS5 and PS5-SELF-TO-ELF are downloaded on the user's own
  machine from their authors' official GitHub repositories, under those projects' terms (see [NOTICE](NOTICE)).
